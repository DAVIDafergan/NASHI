# רעננים (לשעבר רעננה זוכה)

אתר לסריקת קבלות: כל 10 ₪ בעסק שותף = כרטיס להגרלה.

## הרצה במחשב
    npm install
    npm start
פותחים http://localhost:3000. ניהול: http://localhost:3000/admin.html (סיסמת ברירת מחדל: admin1234).
במצב בדיקה (SMS_PROVIDER=console) קוד ה-SMS מודפס בחלון של השרת.

## העלאה לאוויר (Railway)
1. מעלים את התיקייה ל-GitHub (repo פרטי).
2. ב-Railway: New Project ← Deploy from GitHub ← בוחרים את ה-repo.
3. Settings ← Volumes ← Add Volume, נתיב: /data
4. Variables ← מעתיקים את המשתנים מ-.env.example וממלאים.
5. Settings ← Networking ← Generate Domain (או מחברים דומיין משלכם).

## חיבור SMS (InforU)
1. פותחים חשבון ב-inforu.co.il וקונים חבילת SMS.
2. בממשק שלהם: הגדרות ← API ← יוצרים API Token.
3. מאשרים שם שולח (Sender), עד 11 תווים באנגלית, למשל RaananaWin.
4. ב-Railway ממלאים: SMS_PROVIDER=inforu, INFORU_USER, INFORU_TOKEN, SMS_SENDER.
5. נכנסים לאתר, מבקשים קוד לטלפון שלכם. אם לא הגיע, הודעת השגיאה מופיעה ב-Deploy Logs.

## מערכת נגד רמאויות
כל קבלה מקבלת ציון סיכון (0 עד 100), ובפאנל הניהול רואים אותו יחד עם הסיבות:
- **טביעת אצבע לתמונה:** אותה קבלה נחסמת גם אם צולמה מחדש, נחתכה או נדחסה.
- **קריאת קבלה ב-AI (אופציונלי):** מוסיפים ANTHROPIC_API_KEY, והמערכת קוראת את העסק, הסכום, התאריך ומספר הקבלה ומשווה אותם למה שהוזן. היא גם מזהה צילום מסך, עריכה וקבלה בכתב יד. עלות: אגורות לקבלה.
- **ניתוח התנהגות:** מספרי קבלה עוקבים, סכום חריג לעסק, סכום עגול, חשבון חדש עם סכום גבוה, הרבה משתמשים מאותה רשת.
- **חסימת משתמש:** כפתור אחד מבטל את כל הכרטיסים שלו.
- AUTO_APPROVE=true: קבלה שה-AI אימת ושציון הסיכון שלה נמוך מאושרת לבד.

## מה יש בפנים
- התחברות עם קוד SMS (מוגבל: קוד לדקה, 5 בשעה, 5 ניסיונות לקוד)
- סריקת קבלה: צילום, חנות, סכום, תאריך ומספר קבלה
- הגנות: אותה קבלה פעם אחת, קבלות מ-7 ימים אחרונים, עד 3 ביום, עד 3,000 ₪
- נקודה חינם בשבוע בלי רכישה (מסלול חוקי להשתתפות)
- פאנל ניהול: אישור קבלות עם תמונה, עסקים ודוח לכל עסק, הגרלות עם בחירה אקראית לפי כרטיסים, בקשות הצטרפות
- דף לעסקים עם טופס הצטרפות, ותקנון (טיוטה לבדיקת עו"ד)
